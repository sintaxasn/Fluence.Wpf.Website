# PersonPicture

## Description

Use PersonPicture to represent people and contact status in data-heavy views.

| Light | Dark |
| --- | --- |
| ![PersonPicture in light mode](../screenshots/controls/person-picture-light.png) | ![PersonPicture in dark mode](../screenshots/controls/person-picture-dark.png) |

## Example usage

```xml
<fluence:PersonPicture DisplayName="Ana Bowman" />
```

## State and behavior

Initials or an image identify the person; status changes its visual badge.
