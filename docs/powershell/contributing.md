The module has its own source conventions, staging scripts, reference generator, examples, and test gate. Begin with the [module setup and build guide](../../Fluence.Wpf.PowerShell.Module/README.md), then read the root [contribution guide](../../CONTRIBUTING.md) for repository-wide requirements.

Key references:

- [Module source and package layout](../../Fluence.Wpf.PowerShell.Module/README.md#project-layout)
- [Build and test the module](../../Fluence.Wpf.PowerShell.Module/README.md#run-the-module-gate)

- [Runnable examples](../../Fluence.Wpf.PowerShell.Module/examples/README.md)
- [Module design explanation](explanation.md)

Command reference pages are generated from comment-based help in the public function source. Update that help and regenerate the reference when command behavior changes.
